# PCA Lite

A React dashboard built with Vite and the PCA-Lite admin template's Bootstrap theme.

## Development

```sh
npm install
npm run dev
```

Run `npm run build` to create a production build and `npm run lint` to check the
source.

The dashboard is rendered by `src/App.jsx`. Metis SCSS and image assets are
kept under `src/assets/`;
