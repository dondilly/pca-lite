# PCA Lite

A React dashboard built with Vite and the Metis admin template's Bootstrap theme.

## Development

```sh
npm install
npm run dev
```

Run `npm run build` to create a production build and `npm run lint` to check the
source.

The dashboard is rendered by `src/App.jsx`. Metis SCSS and image assets are
kept under `src/metis/`; its license is included at `src/metis/LICENSE.md`.
The current dashboard values are sample data to replace with application data.
